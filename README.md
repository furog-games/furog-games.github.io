# furoggames.github.io

Furog Games web sitesi (GitHub Pages): Tiny Couriers tanıtımı, gizlilik politikası, destek sayfası ve AdMob `app-ads.txt`.

- Sayfaları üret: `python3 tools/build.py` (e-posta ve App Store bağlantısı dosyanın başında)
- `app-ads.txt` kök dizinde olmalı (AdMob doğrulaması için).
