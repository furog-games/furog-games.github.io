# furoggames.github.io

Furog Games web sitesi (GitHub Pages): oyun tanıtımları, gizlilik politikaları, destek sayfaları (TR/EN) ve AdMob `app-ads.txt`.

Oyunlar: Tiny Couriers (`/tiny-couriers/`), Marble Mosaic (`/marble-mosaic/`). Her oyunda `/privacy/` ve `/support/`, Türkçesi `tr/` altında.

- Sayfaları üret: `python3 tools/build.py` (oyunlar `GAMES` listesinde; e-posta ve App Store bağlantıları dosyada)
- `app-ads.txt` kök dizinde olmalı (AdMob doğrulaması için). Tek AdMob hesabı tüm oyunları kapsar.
